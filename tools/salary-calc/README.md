## 工资优化计算器

一个纯前端 HTML 工资优化试算工具，帮助个人理解薪酬结构调整对到手收入、公司成本、个税之间的联动关系。

### 文件与版本

| 文件 | 版本名 | 平衡口径 | 定位 |
|---|---|---|---|
| [`cn-salary-calc-fixed.html`](./cn-salary-calc-fixed.html) | **成本不变版** | **长期稳态**（第4年，社保基数=工资C）公司成本 = 调整前 | k 由公式反推，C 由稳态约束唯一确定 |
| [`cn-salary-calc.html`](./cn-salary-calc.html) | **预交基数版** | **过渡期**（第2年，社保基数=A2 预交基数）公司成本 = 调整前 | k 由用户输入，C 由平衡公式解出 |

### 功能

- 支持两种调整方案对比（方式一：自定义公积金比例；方式二：默认公司/个人各 5%）
- 年度社保基数明细（四年推演，覆盖调整前 → 过渡期 → 稳态）
- 七级累进个税计算（月度换算）
- 支持 B2 ≠ B（社保基数与公积金基数分离）
- 大额医疗（个人固定金额）计入个人扣款与交税基数
- 所有比例、基数、金额可调，实时重算

### 两个版本的核心差异

#### 1. k 的角色（输入 vs 输出）

- **预交基数版**：`k`（公司承担新增社保比例）是页面顶部的用户输入项，取值 0%–100%。
- **成本不变版**：`k` 是**动态反推的输出**，页面不再提供 k 输入框；k 反映过渡期公司实际承担的新增社保比例。

#### 2. C（调整后工资）的求解口径

- **预交基数版**（过渡期平衡，以 A2 预交基数为锚点）：
  ```
  C = A1 + B·rCS + B2·rHFE + (A2−B)·rCS2·k − A2·rCS2 − A2·rHFE2
  ```
  仅在**第2年**（基数=A2）公司成本等于调整前；到第4年（基数=C）公司成本会随 k 偏离调整前值：
  - k=0 → 稳态公司成本**低于**调整前（公司长期省钱，员工承担全部新增）
  - k=100% → 稳态公司成本**高于**调整前（公司长期多花钱）

- **成本不变版**（稳态平衡，两步法）：
  ```
  第一步：C = (A1 + B·rCS + B2·rHFE) / (1 + rCS2 + rHFE2)     ← 长期公司成本严格等于调整前
  第二步：k = (C + A2·rCS2 + A2·rHFE2 − A1 − B·rCS − B2·rHFE) / ((A2−B)·rCS2)   ← 过渡期反推
  ```
  稳态（第4年及以后）公司成本**恒等于**调整前；过渡期（第2、3年）公司成本会临时**高于**调整前，高出的部分即为 k 反映的"公司补贴"。

#### 3. 何时选哪个版本

| 场景 | 适用版本 |
|---|---|
| 想要"长期公司成本持平"的薪酬结构调整方案 | **cn-salary-calc-fixed.html** |
| 已有明确的 k 值（如公司政策已规定了过渡期补贴比例），想看具体到手 | cn-salary-calc.html（预交基数版） |
| 只关心稳态（4 年后）到手，不关心过渡期 | 两者均可，但成本不变版直接给出唯一解 |
| 想对比不同 k 值下的员工到手变化 | cn-salary-calc.html（预交基数版） |

#### 4. 数值等价关系

当预交基数版的 k 恰好等于成本不变版反推的 k 时，两个版本给出**完全相同**的 C 和年度表；反之，若 k 取值不同，两者结果就会偏离。具体反推的 k 值以页面实时计算为准。

### 使用

直接用浏览器打开对应 HTML 即可，无需任何依赖、无需构建、无网络请求，可完全离线使用。

两个版本均可单独使用，具体选择参见上方「何时选哪个版本」表。

### 页面区域速览（两版本一致）

1. **基本参数**：A1（当前税前）、A2 / A2b（预交基数，方式一 / 方式二）、B（当前社保基数）、B2（当前公积金基数，可 ≠ B）
2. **五险一金比例**：调整前的公司/个人各项比例 + 大额医疗（个人固定）
3. **调整后公司比例（方式一）**：默认与调整前相同，可修改
4. **年度社保基数明细（方式一）**：4 年推演表
5. **调整后公司比例（方式二）**：社保比例同方式一，公积金默认 5% / 5%
6. **年度社保基数明细（方式二）**：4 年推演表

年度表列含义：`工资 / 社保基数 / 公司五险 / 公司公积金 / 个人五险 / 个人公积金 / 公司总成本(月) / 公司增加成本 / 公司五险增加成本 / 交税基数 / 个税 / 实际到手 / 实际到手(含公积金)`。

> **扣除项说明**：表中「个人五险」列**未单列「大额医疗」**（个人固定金额，默认 3 元/月），该项已并入「交税基数」扣除和「实际到手」计算，两版本行为一致。
