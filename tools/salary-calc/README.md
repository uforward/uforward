## 工资优化计算器

一个纯前端 HTML 工资优化试算工具，帮助个人理解薪酬结构调整对到手收入的影响。

### 功能

- 支持两种调整方案对比（自定义公积金比例 vs 默认5%）
- 年度社保基数明细（四年推演）
- 七级累进个税计算
- 所有参数可调，实时计算

### 使用

直接用浏览器打开 `cn-salary-calc.html` 即可，无需任何依赖。

### 声明

本工具仅供个人学习参考，帮助理解薪酬结构与五险一金、个税之间的关系。社保缴费基数应按职工实际工资确定，各项比例及政策参数可能因地区、时间而异，请以当地社保局、公积金中心及税务部门最新规定为准。薪酬结构调整可能影响贷款资质、社保待遇等，请综合评估个人实际情况。
